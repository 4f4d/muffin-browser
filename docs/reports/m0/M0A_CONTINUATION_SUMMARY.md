## Performance and distribution

All 40 calibrated Apple M4 launches reached the readiness criterion for their workload. WRY's host measured about 14–21 MiB. Its ten-tab repeat median reached 460.8 MiB summed physical footprint including timing-associated WebKit helpers, compared with 373.4 MiB in the tested Chrome setup. The short run establishes the importance of active WebView count, with only two samples per cohort and engine-helper attribution limits. Firefox and Chrome used disposable profiles. Safari WebDriver required a setting change and its comparison remained unrun. Windows and interactive Linux measurements remain unrun. [Performance report](S5_COMPARATIVE_BASELINES.md), [raw samples](evidence/continuation-s5-macos-raw.json)

Measured fixture archives were approximately 0.55–1.37 MB, including an Ubuntu .deb, three Mac ZIPs and one EXE-only Windows ZIP. The macOS and Ubuntu archives rely on external system engines. The Windows executable used an already installed WebView2 Runtime. ARM64 Windows remains source-only. OS version floors, a clean installer, runtime deployment size, upgrades, signing and real release packages remain separate checks. [Package and runtime report](S8_PACKAGE_RUNTIME.md)
