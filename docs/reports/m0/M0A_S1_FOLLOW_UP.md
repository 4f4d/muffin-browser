## Security recommendation

Use separate WebViews for bundled chrome and remote content. Register the typed native dispatcher and private resources on the trusted view only. In two interactive Mac runs, the trusted chrome invoked the synthetic native command twice around the untrusted attempts. The HTTP control succeeded, the untrusted command and private chrome navigations were denied, and private chrome and bundled-file fetches failed. The fixture page remained visible after the file navigation attempt. The final URL and the mechanism behind that navigation outcome remain unverified. The Mac result supports the proposed boundary. Actual product commands, other engines and broader navigation cases still require validation. [Security assessment](S1_FOLLOW_UP_SECURITY.md), [scope and evidence](spikes/S1-follow-up-macos-wry-tao.md)
