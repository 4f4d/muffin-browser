## Downloads

Two exact lengths and hashes establish transport and explicit collision avoidance in the scratch fixture. The denied attachment tests cancellation at the start decision. Progress, cancellation during transfer, multi-gigabyte downloads, partial-file cleanup, overwrite races, and resumed transfers need focused checks. WRY's public hooks provide start/destination and completion. Use WKDownload, WebKitGTK download signals and WebView2 download operations for richer platform-specific state. Prefer the engine's own cookie context and restrict destination access to a user-selected or app-managed directory. XDG origin metadata identifies a source. Apple quarantine and Windows attachment policy each need real-download and enforcement tests. [Pinned hook and OS sources](evidence/continuation-s4-sources.txt)

The pinned Windows WRY default arguments contain a feature-disable entry named msSmartScreenProtection. The Windows S4 fixture supplied explicit empty additional arguments and therefore did not request that default flag. The runner did not establish SmartScreen enforcement. Audit actual browser arguments and keep protection enabled for the proposed product path before enabling arbitrary remote downloads. [Pinned WebView2 backend source transcript](evidence/continuation-s4-sources.txt)

## PDF and filtering

Prefer the system PDF path as a candidate on engines where the sample displayed. Evidence from those builds does not require shipping an additional PDF.js package. No fallback package was bundled or measured. Validate complex documents, local-file opens, printing and safe external/download fallback on supported releases. The print APIs differ by engine. A print job did not run in S4. [Native capture](evidence/continuation-s4-pdf-macos.png), [GTK capture](evidence/continuation-s4-pdf-x11.png), [print and profile sources](evidence/continuation-s4-sources.txt)

The WebKit JSON rule prevented the sample request in both WebKit engines. WRY navigation blocking and cosmetic hiding operate at different points from native network filtering. The single-rule compilation and page-ready timings are diagnostic samples. Real list size, parse cost and browsing overhead remain unknown. WebView2 offers a separate native WebResourceRequested path with coverage limits. EasyList upstream permits use under either GPLv3-or-later or CC BY-SA 3.0-or-later, with separate externally referenced lists potentially carrying other terms. No list was imported or bundled. List conversion, validation, attribution and the license decision remain open. [Source references](evidence/continuation-s4-sources.txt), [EasyList licence](https://easylist.to/pages/licence.html)

## Private browsing

Use a separate engine store for private browsing and exclude private sessions from Muffin-owned history and session restore. The probes compared normal and private views at the same loopback origin. They cover cookies and localStorage while both views exist. Cache, service workers, history, same-private-session tab sharing, private downloads, app-close erasure, and crash persistence remain open. On macOS use a nonpersistent WKWebsiteDataStore, on GTK an ephemeral WebKit context, and on Windows validated InPrivate controller options with an app-owned data directory and browser-exit coordination. Test teardown and on-disk artifacts before offering the feature. [Pinned profile APIs](evidence/continuation-s4-sources.txt)
