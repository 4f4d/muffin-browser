## Reproducible scope

- Run Python fixture-policy cases with `python3 -m unittest discover -s spikes/s7 -v`. The six cases passed. Cover state transitions in Rust unit tests when the product owns navigation and permission policy. The current locked Rust fixture targets built under `cargo test --offline --locked --manifest-path spikes/s1/wry-tao/Cargo.toml` and contain zero Rust unit tests.
- Run `python3 spikes/s7/check_evidence.py` with ImageMagick available. It checks both S1 boundary log pairs, known Mac keyboard/responder evidence, popup opener and navigation outcomes, matched download hashes and storage isolation, intentional GTK recovery, action pins, and four actual image artifacts. Mac, Windows and X11 overlay captures cross their recorded pane boundaries. The preserved Tauri screenshot is a historical negative decode control.
- The fresh S7 replay of the committed Mac WRY feature fixture reached the privacy/download checks again with a new loopback authority and scratch destination. It used the same synthetic fixture profile policy. [Replay identity](evidence/continuation-s7-replay-identity.txt), [native](evidence/continuation-s7-replay-native.txt), [HTTP](evidence/continuation-s7-replay-content.jsonl), [replay report](evidence/continuation-s7-replay-summary.json)
- S1 has bounded create/load/drop cycles, native evidence for deliberate GTK renderer recovery, and focus and z-order observations in the environments shown. Keep disruption, reconnect, state retention and unexpected renderer recovery as separate native tests. Wider input, realistic scale/IME, desktop graphics and DRM require their allocated interactive or bare-metal paths. [S1 follow-up](M0A_S1_FOLLOW_UP.md), [Wayland controlled termination](evidence/s1-wry-server-wayland-recovery.txt)

Use one fixture corpus and binary command contract. Keep deterministic fixture control outside remote content and scoped to an owned test process. Capture source and executable hashes, exact OS, engine, toolchain, backend and scale. Persist raw native/HTTP traces, exit codes and requested screenshots even when a scenario fails. Put non-deterministic provider and real-desktop cases in the manual matrix. Capture the native view or window relevant to the claim, and assert exact structural properties before interpreting visual results. A compile-only Rust job cannot establish browser workflow behavior.
