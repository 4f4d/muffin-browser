# M3 — Local profile and browser surfaces

Muffin stores settings, history, bookmarks and shortcuts in a native SQLite profile. The address bar ranks local title and URL matches. History and bookmark changes update the trusted chrome through the existing typed messages. Bookmark HTML is parsed in native code, has size and depth limits, and accepts credential-free HTTP and HTTPS entries. Import and export use native file dialogs. [Profile module](../../../crates/muffin/src/profile.rs), [IPC definitions](../../../ui/src/lib/bridge.ts)

- `just verify` passed on a clean Apple Silicon checkout of `1958eef8cdc34b2a1211441246e26dd097093f40`. It ran 83 status and pin tests, one loopback fixture test, 15 chrome tests and 25 Rust tests. It also built debug and release binaries and confirmed that release rejects debug test control. The RustSec audit reported two advisories in the GTK dependency graph. npm audit reported zero vulnerabilities. [Verifier receipt](../platform/m3/macos-arm64-verifier.json)
- Native loopback exercised local search, bookmarks, folders, shortcuts, preferences, clearing recent history and clear-on-exit. A graceful restart kept settings and bookmarks and respected the restore-tabs preference. The native layout probe checked the visible headings of Start, Library and Settings, scrolled the overflowing Library list, and checked the tab fill after switching to light mode. [Native fixture receipt](../platform/m3/macos-arm64-native-smoke.json)
- The selected tab uses a solid fill with an independent keyboard-focus indicator. Start introduces a restrained warm gradient and rounded search field. Settings groups preferences, uses rounded native-select controls, and shows checkmarks for enabled startup options. The library uses scrollable rows and pressed buttons for its two views. Interface Design and Taste Skill informed the styling. Accessibility Engineering informed control semantics and focus. The shadcn-svelte skill supplied field and scroll patterns, and Liquid Glass JS supplied visual references for shape and tint. The toolbar material uses CSS blur with an opaque accessibility fallback.
